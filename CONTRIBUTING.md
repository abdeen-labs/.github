# Contributing

Pull requests are welcome. Every change is reviewed before it merges.

## Ground rules

1. Keep each pull request focused. Separate unrelated changes.
2. If a change affects storage, network access, analytics, or account requirements, update the product’s privacy details with it.
3. Explain what changed and how you tested it. Include screenshots, recordings, or before-and-after examples when they help.

## Process

1. For anything larger than a small fix, open an issue first and describe the problem.
2. Fork, branch, make the change.
3. Open the pull request against `main`. Describe the change and the checks you ran.
4. Respond to review and make requested changes where needed.
5. A maintainer merges after approval.

Repositories that are not public yet do not accept external contributions.

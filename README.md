Organization profile for **Abdeen Labs**, the open-source and experimental division of Abdeen Industries. `profile/README.md` renders on [github.com/abdeen-labs](https://github.com/abdeen-labs).

`profile/assets/` contains the Labs lockup and Roundel seal from `abdeen-brand/exports/labs/svg/components/`.

The files at the repository root — `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `GOVERNANCE.md` — are organization-wide defaults. Every repository in the organization inherits them unless it carries its own copy.
